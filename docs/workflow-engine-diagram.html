Natural language in, audited actions out

“Every day at 10 PM, generate my fraud performance report. If there are at least 10 reviews today, send it to Slack; otherwise do nothing.”

Judgment from models, invariants from code. The planner is the only model step (dashed) — it reads intent and drafts an ordered plan. Everything that can cause an effect is code: feasibility and the executor (the two green anchors) validate the plan, enforce SELECT-only SQL, evaluate conditions, control permissions, schedule, and run only registered tools. A request that names no real tool — “delete all BLOCK decisions” — is rejected before anything executes.
