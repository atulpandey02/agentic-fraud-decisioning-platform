Architecture · Agentic Fraud Decisioning Platform

Stream → decide → govern → automate

The spine runs left→right: feature store → supervisor → governance → decisions. On the right, the decisions store fans out to two guarded surfaces — Agentic BI (ask in English) and the workflow engine, which the BI page feeds (send / schedule a result) and a Scheduler drives on a time trigger; every recurring report replays validated SQL and lands in an auditable Outbox. The two green nodes are the focal points — the multi-agent supervisor (the decision core) and the Snowflake decisions store (system of record). Dashed = LLM call. Guardrails are enforced in code at the BI surface (SELECT-only AST guard) and the workflow engine (feasibility + deterministic conditions + validated-SQL replay).
